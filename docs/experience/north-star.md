# North Star

> Status: Superseded design hypothesis. Retained because the interface probe revealed a product-architecture correction.

The north star is a desktop workspace for brand and marketing teams. It should feel like a precise editorial operations system rather than a generic AI dashboard: calm, inspectable, visually literate, and explicit about which decisions belong to people, policy, deterministic tools, and models.

## Product promise

The application lets a team build a durable brand brain and complete configured production workflows. Creative-control policy should make the workflow dependable without requiring ordinary users to operate the architecture. Every meaningful exception remains explainable without turning the interface into a metadata form.

## Visual principles

- Put the work and its governing decisions on the same screen.
- Make exactness promises and material exceptions visible before production begins.
- Treat canon, approvals, and prohibitions as operational state, not decorative badges.
- Use progressive disclosure for provenance, confidence, and version history.
- Distinguish deterministic composition from model generation in plain language.
- Keep review actions specific: approve an output, approve guidance, and promote to canon are separate actions.
- Prefer a restrained editorial rhythm, strong typography, warm neutral surfaces, and one controlled signal color.

## Learning from the first anchor view

The first mockup focused on a hybrid production job at the policy-review stage. It combined:

- the production request;
- a mode selector and compiled policy;
- locked canonical assets;
- flexible world guidance;
- output preview;
- deterministic-composition record;
- drift and quality evaluation;
- approval and revision actions;
- proposed memory write-back.

The mockup dropped into a deep generation workflow without establishing the application, the user's path, or why the user should choose a mode. It demonstrated that constrained, hybrid, and editorial belong primarily in workflow-stage configuration. Future north-star work should begin with the complete product map and end-to-end journeys.
